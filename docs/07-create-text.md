# สร้าง QR / บาร์โค้ดจากข้อความ

เครื่องมือแปลงข้อความเป็น QR และบาร์โค้ด **ไม่บันทึกข้อมูล** — ไม่มี API, ไม่มีฐานข้อมูล, ไม่มี localStorage

| หน้า | ใช้เมื่อ |
|---|---|
| `/` | หน้าหลัก พิมพ์ข้อความเอง |
| `/qr?text=...` | รับข้อความจากลิงก์ (แชร์ให้คนอื่นเปิดแล้วเห็นโค้ดทันที) |

## การใช้งาน

1. เปิด `/` (หรือเมนู “สร้าง QR” ที่ header)
2. พิมพ์ข้อความ (ไม่เกิน 500 ตัวอักษร)
3. สลับแท็บ **QR** / **บาร์โค้ด**
4. กด **คัดลอกลิงก์** หรือ **แชร์**

เมื่อมีข้อความ ระบบจะเปลี่ยน URL เป็น `/qr?text=...` เพื่อให้ refresh/แชร์ได้

**เมื่อเปิดจากลิงก์ที่มีข้อความ** (`/qr?text=...`):
- ไม่แสดงช่องกรอก — แสดงข้อความ (อ่านอย่างเดียว) + QR/บาร์โค้ดทันที
- มีปุ่ม **คัดลอกลิงก์ / แชร์ / สร้างใหม่**
- “สร้างใหม่” จะล้างข้อความ กลับไปหน้าพิมพ์ และเปลี่ยน URL เป็น `/qr`

## ข้อจำกัด

| เรื่อง | รายละเอียด |
|---|---|
| บาร์โค้ด | Code 128 รองรับเฉพาะ ASCII ไม่เกิน 80 ตัว — ข้อความไทย/ยาวเกินจะแสดงเหตุผลและใช้ QR แทน |
| QR | รองรับข้อความทั่วไป (แนะนำ ≤ 500 ตัวอักษรเพื่อให้สแกนง่าย) |
| ความเป็นส่วนตัว | ข้อความอยู่ใน URL และประวัติเบราว์เซอร์ — อย่าแชร์ลิงก์ที่มีข้อมูลส่วนตัว |
| ที่เก็บ | ไม่มี — refresh แล้วข้อความยังอยู่เพราะอยู่ใน URL เท่านั้น |

## ตัวอย่างลิงก์

```
/qr?text=SAVE50
/qr?text=https%3A%2F%2Fexample.com
```
