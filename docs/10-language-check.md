# ตรวจคุณภาพภาษา description จาก OCR

ตอนนี้หน้า Review และ Baseline มีตัวตรวจแบบ **offline heuristic** — ไม่ส่งข้อความออกไปที่ใด

## ตรวจอะไร

| จุดตรวจ | ตัวอย่าง |
|---|---|
| คำไทยที่ไม่อยู่ในคลังคำ | คำที่อาจสะกดผิด/ตัดคำผิด |
| ตัวอักษรซ้ำผิดปกติ | `ลดดด` |
| วรรณยุกต์ซ้ำ | คำที่มีวรรณยุกต์เกิน 1 ตัว |
| ขึ้นต้นด้วยสระ/วรรณยุกต์ | `่าก` |
| OCR confidence ต่ำ | ลดคะแนนเพิ่ม |

- ข้ามชื่อแบรนด์/อังกฤษ/รหัส/URL/ตัวเลข เพื่อลด false positive
- เลขไทย (๐-๙) ถูกแปลงเป็นอารบิกก่อนตรวจ

## แสดงผล

- **คะแนนภาษา** เช่น `ภาษา 93%`
- ระดับ: ดี / ควรตรวจ / ควรแก้
- รายการ “คำที่ควรตรวจ” + เหตุผล (สูงสุด 5 คำ)
- **ไม่แก้ข้อความให้อัตโนมัติ** — ผู้ใช้ยังแก้เองในฟอร์ม

## ข้อจำกัดที่รู้

1. คลังคำเป็นชุดคำที่คัดมา ไม่ใช่พจนานุกรมเต็ม — คำไทยที่ถูกต้องแต่หายากอาจถูก flag
2. ยังไม่ตรวจไวยากรณ์เชิงความหมาย (ประโยคถูกหลักแต่สื่อผิด)
3. ชื่อร้าน/เมนู/แบรนด์ภาษาไทยบางคำอาจถูก flag — เพิ่มใน `COMMON_THAI` ได้ที่ `lib/language-check.ts`
4. ยังไม่ตรวจภาษาอังกฤษเชิงลึก (ข้ามคำ Latin)

## ถ้าต้องการแม่นขึ้น

- ต่อ **PyThaiNLP** (`spell`/`correct`) เป็น service
- ต่อ **LLM** สำหรับแก้ประโยค โดยแสดง diff และให้ผู้ใช้ยอมรับ
- เพิ่มคลังคำเฉพาะธุรกิจ (แบรนด์, เมนู, คำโปรโมชัน)
