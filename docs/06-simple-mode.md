# โหมดง่าย — เก็บคูปองอย่างเดียว

ไฟล์เดียวจบ: [`public/simple.html`](../public/simple.html) — ไม่มี OCR, ไม่มี QR reader, ไม่มี Google Sheets, ไม่ต้องติดตั้งอะไร และเป็นเลย์เอาต์มือถืออย่างเดียว (กว้างสุด 480 px)

> โหมดนี้เก็บในเบราว์เซอร์เครื่องเดียว **ไม่แยกตาม user id** — ถ้าต้องการแยกหลาย user ใช้โหมดเต็มที่ `/user/{id}`

เหมาะกับกรณี: **อยากเก็บ Screenshot คูปองไว้ที่เดียว เปิดดูตอนจ่ายเงิน แล้วกดใช้แล้ว** เท่านั้น

---

## วิธีเปิด

| วิธี | คำสั่ง | หมายเหตุ |
|---|---|---|
| เปิดไฟล์ตรง ๆ | ดับเบิลคลิก `public/simple.html` | เร็วที่สุด; บางเบราว์เซอร์อาจจำกัด IndexedDB บน `file://` |
| ผ่าน dev server | `npm run dev` → เปิด `http://localhost:3000/simple.html` | แนะนำ ถ้าจะใช้จริงบนเครื่อง |
| โฮสต์เป็น static | อัปโหลด `simple.html` ขึ้น hosting ใดก็ได้ | ไม่ต้องมี backend |

หน้าเต็ม (OCR/QR/Google Sheets) ยังอยู่ที่ `/` และมีลิงก์ “โหมดง่าย” ที่ footer

---

## ฟีเจอร์

- เพิ่มคูปอง: อัปโหลด / ลากมาวาง / วางจาก clipboard (⌘V) / ถ่ายรูป
- ตั้งชื่อ, วันหมดอายุ, บันทึกเพิ่มเติม
- ย่อรูปอัตโนมัติ (ด้านยาวสุด 1,280 px, WebP fallback JPEG, เป้าหมาย ≤ 600 KB) ก่อนเก็บ
- การ์ดแสดง badge: ยังไม่ใช้ / เหลือ X วัน / หมดอายุ / ใช้แล้ว
- กด “ใช้แล้ว” / “ยกเลิกใช้แล้ว” ได้
- เปิดดูรูปเต็มจอ (QR อยู่ในรูปต้นฉบับ), แก้ไข, ลบ
- ค้นหาชื่อ/โน้ต, แท็บ ทั้งหมด / ยังไม่ใช้ / ใช้แล้ว
- สำรองข้อมูลเป็น JSON และนำเข้ากลับ

---

## ข้อมูลเก็บที่ไหน

- เก็บใน **IndexedDB ของเบราว์เซอร์นี้** (`coupon-wallet-simple`)
- รูปเก็บเป็น **Blob** (ไม่ใช่ Base64) — ประหยัดพื้นที่และโหลดเร็วกว่า
- ไฟล์สำรอง JSON จะแปลงเป็น Base64 เฉพาะตอน export/import
- ไม่อัปโหลดขึ้นเซิร์ฟเวอร์ ไม่ออกจากเครื่อง
- ข้อมูลผูกกับ origin:
  - เปิดผ่าน `http://localhost:3000/simple.html` → ข้อมูลอยู่กับ origin นี้
  - เปิดไฟล์ตรง ๆ → ข้อมูลอาจแยกตามไฟล์/เบราว์เซอร์
  - เปลี่ยนพอร์ตหรือโดเมน → มองไม่เห็นข้อมูลเดิม
- ล้าง browser data / ใช้โหมดไม่ระบุตัวตน → ข้อมูลหาย
- แต่ละเครื่อง/เบราว์เซอร์แยกกัน ไม่ sync

**สำรอง:** กด “สำรองข้อมูล” ที่ footer → ได้ไฟล์ `coupons-backup-YYYY-MM-DD.json`
**กู้คืน:** กด “นำเข้า” → เลือกไฟล์ (รายการเดิมไม่ถูกแทนที่; ใบที่ id ซ้ำจะถูกสร้างเป็นใบใหม่)

## ข้อจำกัด (โดยตั้งใจ)

| ไม่มี | เพราะ |
|---|---|
| OCR อ่านชื่อ/ส่วนลดอัตโนมัติ | โหมดนี้เน้นเร็วและเบา — ผู้ใช้พิมพ์ชื่อเอง |
| อ่าน QR จากรูป | เปิดดูรูปต้นฉบับซึ่งมี QR อยู่แล้ว |
| บันทึกลง Google Sheets/Drive | เก็บในเครื่องอย่างเดียว |
| แจ้งเตือนหมดอายุ | แค่แสดง badge |
| หลายเครื่อง/แชร์ให้คนอื่น | ไม่มีบัญชี/เซิร์ฟเวอร์ |

ถ้าต้องการฟีเจอร์เหล่านี้ ใช้โหมดเต็มที่ `/` (ดู [`05-setup.md`](05-setup.md))

## ทดสอบด้วยมือ (5 นาที)

1. เปิดหน้า → เห็น empty state
2. เพิ่มคูปอง 1 ใบ (รูป + ชื่อ + วันหมดอายุพรุ่งนี้) → การ์ดขึ้น badge “เหลือ 1 วัน”
3. รีเฟรชหน้า → ข้อมูลยังอยู่
4. กด “ใช้แล้ว” → การ์ดจางลง + แท็บใช้แล้วมี 1 ใบ
5. กด “สำรองข้อมูล” → ได้ไฟล์ JSON
6. ลองลบคูปอง → หายจากรายการ
7. นำเข้าไฟล์สำรองกลับ → คูปองกลับมา
